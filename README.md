# Amazon Prime Video 未視聴ウォッチリストチェッカー

Amazon Prime Video（amazon.co.jp）のウォッチリストを巡回して、**未視聴エピソードがある作品**を一覧表示する Chrome 拡張機能（Manifest V3）です。

## 何をするものか

Prime Video のウォッチリストでは、各作品にホバーしたときに表示される再生ボタンの文言が視聴状態で変わります。

- 「シーズン○エピソード○の**続きを観る**」→ そのエピソードは視聴済み側（途中まで見ている）
- 「エピソード○**を再生**」→ そのエピソードは未視聴（= 新しいエピソードが来ている候補）

Distill Web Monitor のようなページ監視ツールはこのホバー表示を取得できないため、その判定ができませんでした。この拡張は、ウォッチリストページ上で各カードにプログラムからホバーイベントを送ってホバーカードを出現させ、ボタンの文言を読んで判定します。

## インストール（開発者モード）

1. このフォルダを解凍した状態で置く
2. Chrome で `chrome://extensions` を開く
3. 右上の「デベロッパーモード」を ON
4. 「パッケージ化されていない拡張機能を読み込む」で、このフォルダ（manifest.json がある場所）を選ぶ

## 使い方

1. amazon.co.jp にログインしておく
2. 拡張アイコンをクリックしてポップアップを開き、「ウォッチリストをチェック」を押す
   - ウォッチリストのタブが開いて（または前面化して）、自動で巡回が始まります
3. 巡回中はウォッチリストページの右上にパネルが出て、進捗と結果がリアルタイムで増えていきます
   - 巡回は上から下へスクロールしながら1作品ずつホバーを再現します。作品数によりますが、1作品あたり約0.7〜2.5秒かかります（ホバーに反応がない作品は約1.2秒で見切ります）
   - 終了するとページは自動で最上部に戻ります
   - 途中でやめたいときはパネルの「中止」ボタン
4. 終わったら、もう一度拡張アイコンを押すとポップアップにも前回結果が表示されます
   - 結果は「未視聴あり」「視聴済み側・続きを観る」「判定不能」の3グループで表示され、タイトルをクリックすると作品ページが開きます

## 判定ルール

| ボタンの文言 | 判定 |
|---|---|
| 「〜の続きを観る」を含む | 視聴済み側 |
| 「エピソード○を再生」を含む | 未視聴あり |
| それ以外（「今すぐ観る」など）／ボタンが取れない | 判定不能 |

- 「予告編を再生」のような別ボタンと取り違えないよう、エピソード判定できる文言を優先して読みます
- 映画はエピソードの概念がないため、基本的に「判定不能（今すぐ観る）」側に入ります

## 注意点・既知の制限

- **初回はキャリブレーションが必要です。** 実サイトのホバーカードのDOM構造はログインした状態でしか確認できないため、複数の出現パターン（カード内展開／ポータル表示／新規要素の出現）に対応する汎用実装になっています。うまく判定できない作品があった場合は開発側に知らせてください。各作品について「どのボタン文言が・どこで見つかったか」「ホバー周辺のHTML断片」を記録した診断ログ（`pv-checker-debug.json`）を出す機能があり、それでセレクタを実物に合わせて調整できます（ v0.1.2 では診断ログの保存ボタンは UI 上いったん非表示にしてあります。必要なときは表示版を出します）
- 「続きを観る」判定の作品は、そのエピソードの視聴途中の状態です。視聴途中のエピソードがある作品にさらに次のエピソードが追加されたケースは、この方式では検出できません（ボタンが「続きを観る」のままになるため）
- ページの仕様変更（クラス名やホバー挙動の変更）で動かなくなることがあります。その場合も診断ログが手がかりになります
- 巡回中はウォッチリストのタブを操作しないでください（スクロールやホバーが競合します）
- この拡張は amazon.co.jp のログイン状態をそのまま使うだけで、アカウント情報や Cookie を外部に送信しません。通信は amazon.co.jp への通常のページ表示だけです

## ファイル構成

- `manifest.json` — 拡張の定義（権限は tabs / storage / scripting と amazon.co.jp のホスト権限のみ）
- `background.js` — ポップアップからの開始指示を受けてウォッチリストのタブを開く／前面化する
- `content.js` — ウォッチリストページ上での巡回・ホバー再現・判定・パネル表示
- `content.css` — ページ内パネルのスタイル
- `popup.html` / `popup.js` — 拡張ポップアップ（開始ボタン＋前回結果）

## 動作確認済みの範囲

- 判定ロジック（文言→判定、URL→作品ID抽出）の単体テスト
- 本物の Prime Video を模したモックのウォッチリストページ（ホバーで遅れてボタンが出るカード×4種）を使ったヘッドレス Chrome での巡回テスト: 「続きを観る」→視聴済み側、「エピソード○を再生」→未視聴、「今すぐ観る」→判定不能、ボタンなし→判定不能、の振り分けとポップアップへの結果表示を確認
- 実サイト（ログイン状態の本物のウォッチリスト）での確認は未実施です。初回実行結果と診断ログで調整する前提です
